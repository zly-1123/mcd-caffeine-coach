# 麦咖啡因管家 · mcd-caffeine-coach

> 把麦当劳的每一杯饮品，翻译成**咖啡因当量**、**代谢时间线**和**今晚几点前必须喝完**。

麦当劳 MCP Server 提供 35 个工具、160 条餐品营养数据，覆盖能量、蛋白质、脂肪、碳水化合物、钠、钙——
**唯独没有一个字提到咖啡因**。

所以你能查到一杯中杯美式含 13 kcal、1g 蛋白质、0g 脂肪，却查不到它含多少咖啡因，更查不到"现在 8 点喝这杯，今晚几点能睡着"。

麦咖啡因管家补的就是这块空白。

---

## 它回答什么问题

点餐助手都在回答"吃什么最省"，本项目的答案是三个从来没人认真算过的问题：

1. **这杯到底含多少咖啡因？**（官方数据缺失，本项目建设了公开可审计的换算模型）
2. **我现在喝，今晚几点前必须喝完？**（一阶消除模型 + 就寝残余阈值倒推）
3. **我今天已经喝了多少，还能不能续？**（读取历史订单，累加当日摄入）

以及一个顺带的："同样提神，哪杯每块钱最划算？"

---

## 目标用户

- **下午三点后想喝咖啡又怕睡不着的上班族**——这是最核心的人群，他们不缺"哪杯便宜"，缺"几点以后别喝"。
- **每天固定一杯、但说不清自己一天喝了多少的人**——需要累计口径而不是单杯口径。
- **对咖啡因敏感、正在减量或控制睡眠的人**——需要可调阈值和半衰期。
- **替别人点单的人**（给同事、给家人）——需要知道这杯对对方的实际影响。

## 安装

无需任何第三方依赖，只需要 Python 3.8+ 和标准库。

```bash
git clone https://github.com/zly-1123/mcd-caffeine-coach.git
cd mcd-caffeine-coach
cp .env.example .env        # Windows: copy .env.example .env
# 编辑 .env，把 YOUR_MCP_TOKEN 换成你在 https://open.mcd.cn/mcp 控制台申请到的 Token
```

MCP Token 申请方式见 [麦当劳 MCP Server 官方指南](https://github.com/M-China/mcd-mcp-server)。

**不想申请 Token 也能完整试用**：项目内置了真实采集的数据快照，所有命令加 `--offline` 即可离线运行。

## 数据来源与模型可信度

本项目坚持一条原则：**官方数据是官方数据，估算是估算，两者绝不混同。**

| 数据 | 来源 | 性质 |
|---|---|---|
| 餐品名称、现价、原价、优惠类型、门店在售状态 | 麦当劳 MCP `query-meals` | 官方实时数据 |
| 营养成分（能量/蛋白/脂肪/碳水/钠/钙） | 麦当劳 MCP `list-nutrition-foods` | 官方数据 |
| 特调选项（冰量、加料等） | 麦当劳 MCP `query-meal-detail` | 官方数据 |
| 实际应付金额 | 麦当劳 MCP `calculate-price` | 官方计算结果 |
| **咖啡因含量** | **本项目模型** | **估算，非官方数据** |
| 半衰期、每日上限、就寝阈值 | 公开药代动力学参考值 + 本项目设定 | 估算，可配置 |

咖啡因数值全部集中在 [`data/caffeine_model.json`](data/caffeine_model.json)，每条规则都写明折算依据（例如"美式按 小1/中2/大3 份浓缩折算，每份 63mg"）。**你可以直接改这个文件来覆盖任何数值**，代码不会把估算值包装成官方数据——输出里每一处咖啡因都会标注"估算"。

模型有意**不使用体重线性外推**：咖啡因清除率主要由 CYP1A2 酶活性决定，与体重没有稳定比例关系，按体重换算只会制造虚假的精确感。

## 测试

```bash
python -m unittest discover -s tests -v
```

18 项测试覆盖：杯型与温度解析、规则优先级（燕麦奶铁不会被误判成燕麦奶、柠檬红茶不会被误判成普通红茶）、零咖啡因饮品、未收录餐品的兜底行为、一阶消除、截止时刻反解、累计残余、每日预算。

所有数值结论都能离线复现，**没有任何一个数字由大模型口算产生**。

## 与已有项目的区别

截至报名期，本赛道 235 个唯一项目中有 60+ 个在做"省钱/券组合优化"、50+ 个在做"营养控卡"、25+ 个在做"人格测试/年度报告"。

饮品线只有 1 个项目（[mcd-cafe-decoder](https://github.com/clairegu12/mcd-cafe-decoder)），它用非负最小二乘解卷积反推每杯麦咖啡的配方构成，是**静态分析报告**。

麦咖啡因管家的区别在于：**它把饮品当成有时间轴的东西**。同样是"这杯含多少咖啡因"，本项目的结论是"你 20:00 已经不能喝它了，最晚 13:08"，而这是可以每天用一次、并且会随时间变化的答案。
